# 헬스장 맵 에디터 — 단계별 AI 프롬프트 가이드

> 기구 등록 2단계: 헬스장 맵 등록 기능을 Konva.js로 구현하기 위한 단계별 프롬프트 모음

---

## 전체 구현 흐름

```
1단계: 맵 캔버스 기초 셋업
    ↓
2단계: 공간 구획 그리기 (벽, 구역)
    ↓
3단계: 기구 배치 및 드래그
    ↓
4단계: 기구 등록 연동 (선택 → 등록 폼)
    ↓
5단계: 저장 및 불러오기
```

---

## Step 1. 맵 캔버스 기초 셋업

**목표**: Konva.js Stage와 Layer를 초기화하고, 반응형 캔버스 + 격자(grid) 배경을 만든다.

```
Konva.js를 사용해서 헬스장 맵 에디터의 기초 캔버스를 구현해줘.

[요구사항]
- Stage 크기: 부모 컨테이너에 맞게 동적으로 계산 (반응형)
- Layer 구조:
  • gridLayer: 배경 격자선 (변경 없음, 고정)
  • roomLayer: 공간/구획 도형
  • equipmentLayer: 기구 아이콘
  • uiLayer: 선택 핸들, 툴팁 등 UI 요소
- 격자:
  • 기본 셀 크기 40px (1칸 = 실제 1m로 매핑)
  • 연한 회색 선 (#e5e7eb), 5칸마다 조금 더 진하게 (#d1d5db)
- 확대/축소: 마우스 휠로 0.5x ~ 3x 범위, 중심 기준 줌
- 패닝: 스페이스바 누른 채 드래그 or 마우스 중클릭 드래그
- 현재 줌 레벨과 마우스 좌표(미터 단위)를 상태바에 표시

[기술 스택]
- React + Konva.js (react-konva)
- 상태관리: Zustand
- TypeScript 사용
```

---

## Step 2. 공간 구획 그리기 (벽, 구역)

**목표**: 사용자가 헬스장 내부 공간을 직접 그릴 수 있게 한다.

```
Step 1에서 만든 캔버스에 공간 구획 도구를 추가해줘.

[구획 도구 종류]
1. 사각형 구역 그리기
   - 클릭 + 드래그로 직사각형 구역 생성
   - 구역 종류 선택: 웨이트존 / 카디오존 / 스트레칭존 / 샤워실 / 락커룸 / 기타
   - 종류별 배경색 자동 적용 (반투명)
2. 벽 그리기
   - 두 점 클릭으로 선분 추가
   - 연속 클릭으로 폴리라인, 더블클릭으로 닫기
   - 두께: 8px, 색상: #374151
3. 기둥 추가
   - 클릭 위치에 원형 또는 사각형 기둥 배치
   - 기본 크기 20px

[구획 편집]
- 선택 도구(V): 클릭으로 선택, shift+클릭 다중 선택
- 선택된 도형: 파란 핸들로 크기 조절, 드래그로 이동
- Delete 키: 선택 도형 삭제
- 구역 라벨: 중앙에 구역명 텍스트 표시

[구역 색상 팔레트]
- 웨이트존: #dbeafe (파란계열)
- 카디오존: #dcfce7 (초록계열)
- 스트레칭존: #fef9c3 (노란계열)
- 샤워실/락커룸: #f3e8ff (보라계열)
- 기타: #f3f4f6 (회색)
```

## Step 3. 기구 배치 및 드래그

**목표**: 등록된 기구를 맵에 아이콘으로 배치하고, 드래그로 위치를 조정한다.

```
헬스장 맵에 기구 배치 기능을 구현해줘.

[기구 아이콘 표현]
- 각 기구는 캔버스 위에 그룹(Group)으로 표현
- 그룹 구성:
  • 배경 사각형 (기구 타입별 색상, 격자 1~2칸 크기)
  • 기구 카테고리 이코노그래피 (SVG 아이콘 or Konva 도형으로 단순화)
  • 하단 라벨: 기구명 텍스트
  • 우상단 배지: 기구 번호 (예: #03)

[기구 카테고리별 색상]
- 유산소: #3b82f6 (파랑)
- 웨이트머신: #f59e0b (주황)
- 프리웨이트: #10b981 (초록)
- 스트레칭: #8b5cf6 (보라)

[배치 방법]
- 좌측 사이드패널에 등록된 기구 목록 표시
- 기구 항목을 캔버스로 드래그 앤 드롭하면 배치
- 배치 시 격자에 스냅 (40px 단위)
- 배치된 기구는 캔버스 내에서 자유 이동 (드래그)

[기구 상태 표시]
- 배치됨: 정상 표시
- 점검중: 주황 테두리 + 🔧 오버레이
- 사용불가: 빨간 테두리 + 반투명 처리

[컨텍스트 메뉴]
- 기구 우클릭 시 메뉴:
  • 기구 정보 보기
  • 상태 변경
  • 이 기구로 이동 (등록 폼 열기)
  • 배치 제거

[충돌 감지]
- 기구를 드롭할 때 다른 기구와 겹치면 빨간 하이라이트
- 겹친 상태로 놓으면 경고 토스트 표시 후 원위치
```

## Step 4. 기구 등록 플로우 연동

**목표**: 맵에서 위치를 선택하는 행위가 기구 등록 폼의 2단계와 연결된다.

```
기구 등록 2단계 폼과 헬스장 맵을 연동해줘.

[시나리오]
1. 관리자가 기구 등록 1단계에서 기구 기본 정보 입력 (이름, 카테고리, 모델명 등)
2. "다음: 위치 지정" 버튼 클릭 → 2단계로 이동
3. 2단계 화면: 헬스장 맵이 전체 표시됨
4. 맵에서 원하는 위치 클릭 → 미리보기 기구 아이콘이 해당 위치에 표시됨
5. 위치 확정 버튼 클릭 → 좌표 저장 (gridX, gridY 정수 기준)
6. 저장 완료 → 맵에 기구 반영, 목록 업데이트

[2단계 UI 구성]
- 상단: "헬스장 맵에서 기구를 배치할 위치를 클릭하세요" 안내 문구
- 중앙: 맵 캔버스 (전체 너비, 높이 60vh)
- 우측 사이드 패널:
  • 선택된 위치 정보 (구역명, 격자 좌표)
  • 주변 기구 목록 (반경 3칸 이내)
  • "이 위치에 배치" 확정 버튼
  • "위치 초기화" 버튼
- 하단: "이전" / "등록 완료" 버튼

[인터랙션 상세]
- 맵 호버: 마우스 위치에 반투명 미리보기 아이콘 따라다님
- 클릭: 해당 격자 셀에 스냅하여 위치 확정
- 이미 기구가 있는 셀 클릭 시: "이미 기구가 배치된 위치입니다" 알림

[저장 데이터 구조]
{
  equipmentId: string,
  position: {
    gridX: number,      // 격자 X 좌표
    gridY: number,      // 격자 Y 좌표
    zoneId: string,     // 소속 구역 ID
    zoneName: string    // 소속 구역명
  }
}
```

## Step 5. 맵 저장 및 불러오기

**목표**: 맵 레이아웃(구획, 기구 위치)을 JSON으로 직렬화하여 저장/복원한다.

```
헬스장 맵 상태를 저장하고 불러오는 기능을 구현해줘.

[저장 데이터 스키마]
{
  "version": "1.0",
  "gymId": string,
  "mapMeta": {
    "width": number,      // 실제 너비 (미터)
    "height": number,     // 실제 높이 (미터)
    "gridSize": 40        // px per meter
  },
  "zones": [
    {
      "id": string,
      "type": "weight" | "cardio" | "stretching" | "locker" | "shower" | "other",
      "name": string,
      "rect": { "x": number, "y": number, "width": number, "height": number }
    }
  ],
  "walls": [
    {
      "id": string,
      "points": number[]   // [x1,y1, x2,y2, ...]
    }
  ],
  "pillars": [
    {
      "id": string,
      "x": number, "y": number,
      "shape": "circle" | "rect"
    }
  ],
  "equipment": [
    {
      "equipmentId": string,
      "gridX": number,
      "gridY": number,
      "zoneId": string,
      "rotation": 0 | 90 | 180 | 270
    }
  ]
}

[저장 방법]
- 자동 저장: 변경 발생 후 3초 디바운스 → localStorage 임시 저장
- 수동 저장: "저장" 버튼 → API POST /gyms/{gymId}/map
- 저장 상태 표시: "저장됨 · 2분 전" or "저장 중..." or "저장 안됨 (변경사항 있음)"

[불러오기]
- 진입 시 API GET /gyms/{gymId}/map → 맵 복원
- 맵 데이터 없으면 새 맵 생성 모드 (기본 크기 20m x 15m)

[내보내기 기능]
- PNG 내보내기: Konva stage.toDataURL() 사용, 고해상도 (scale: 2)
- JSON 내보내기: 맵 데이터 다운로드

[이력 관리]
- Undo/Redo: Ctrl+Z / Ctrl+Y (최대 30단계)
- 이력 스택: Zustand 상태에 배열로 관리
- 각 이력 항목: 변경 타입 + 이전 상태 스냅샷
```

## 보너스: 전체 통합 프롬프트 (한 번에 구현 요청 시)

위 5단계를 모두 구현된 상태로 한 번에 요청하고 싶을 때 사용:

```
헬스장 기구 등록 시스템의 맵 에디터를 Konva.js(react-konva)로 구현해줘.
아래 스펙을 모두 포함해야 해.

[핵심 기능]
1. 반응형 캔버스 (격자 배경, 줌/패닝)
2. 공간 구획 그리기 (구역, 벽, 기둥)
3. 기구 드래그 앤 드롭 배치 (격자 스냅, 충돌 감지)
4. 기구 등록 2단계 폼과 연동 (위치 선택 → 좌표 저장)
5. 맵 상태 JSON 직렬화/역직렬화 + Undo/Redo

[기술 스택]
- React + TypeScript
- react-konva (Konva.js)
- Zustand (상태관리)
- Tailwind CSS (UI)

[우선순위]
- 1순위: 기구 배치 + 2단계 폼 연동 (핵심 사용자 플로우)
- 2순위: 공간 구획 그리기
- 3순위: 저장/불러오기, Undo/Redo

파일은 다음과 같이 분리해줘:
- GymMapEditor.tsx (메인 컴포넌트)
- useMapStore.ts (Zustand 스토어)
- MapCanvas.tsx (Konva 캔버스)
- EquipmentLayer.tsx (기구 레이어)
- RoomLayer.tsx (구획 레이어)
- SidePanel.tsx (기구 목록 패널)
- types/map.ts (타입 정의)
```

## 팁: AI에게 전달할 때 주의사항

- **컨텍스트 유지**: 각 단계 프롬프트 앞에 "이전에 만든 코드를 기반으로" 명시
- **파일 첨부**: 이전 단계 코드를 파일로 첨부하거나 붙여넣기
- **점진적 구현**: 한 번에 전부보다 단계별로 구현하면 품질이 높음
- **Konva 버전 명시**: `react-konva@18` + `konva@9` 조합 권장
